# Đảo ký ức (Memory Isles) — ghi chú cho Claude

## Git
- Sửa xong thì commit rồi push thẳng vào `main` (`git push origin HEAD:main`), không cần tạo PR hay chờ duyệt.
- Nếu `main` có commit mới thì `git pull --rebase origin main` trước khi push, không force-push lên `main`.
- Trước khi push: `npm run build` phải chạy được.

Xem thêm `README.md` (cấu trúc, cách thêm ảnh/đảo) và `docs/island-playbook.md`.
